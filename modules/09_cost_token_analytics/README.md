# Module 09: Token Rollup, Cost Attribution & Node Bottleneck Analytics

Welcome to **Module 09** of the *LangGraph + LangSmith + Grafana Observability* curriculum.

## 🎯 Learning Objectives
By completing this module, you will:
1. Programmatically query and inspect execution traces using `client.list_runs()` and `client.read_run()`.
2. Perform **per-node token attribution** to determine which agent or tool consumes the most tokens.
3. Apply a **multi-provider pricing matrix** to calculate exact dollar costs for every model execution.
4. Build an automated **SRE Bottleneck Analyzer** that surfaces the top slowest and most failure-prone graph nodes.

---

## 📂 Scripts in this Module

| Script | Purpose | What it Teaches |
|---|---|---|
| `01_read_run_metadata_client.py` | LangSmith Client SDK | Fetching past execution runs, filtering by project and run type, and extracting metadata. |
| `02_per_node_token_attribution.py` | Per-Node Token Decomposition | Decomposing prompt and completion token counts across parent graphs and child nodes. |
| `03_cost_calculation_engine.py` | Multi-Provider Cost Engine | Calculating exact USD cost based on token consumption and provider pricing rates. |
| `04_bottleneck_failure_analyzer.py` | Automated SRE Analyzer | Identifying high-latency outliers and failure bottlenecks across historical runs. |

---

## 🔍 What to Check in the LangSmith UI

After running `04_bottleneck_failure_analyzer.py`:
1. Open [LangSmith Cloud](https://smith.langchain.com).
2. Go to your project and switch to the **Analytics / Cost** view.
3. Compare the UI cost charts against the programmatic output generated by `03_cost_calculation_engine.py`.
4. Use the insights to optimize token prompts and reduce unnecessary sub-agent loops!
